# Roadmap

## v0.1 - evidence-backed core

- 42 original portable Agent Skills.
- Safe discovery/install/update/remove CLI.
- Structural validation for every skill.
- Dependency-free deterministic helpers for high-signal checks.
- Research corpus and scored opportunity map.
- GitHub Actions validation on supported Python versions and operating systems.
- Generated skill catalog and honest validation matrix.

## v0.2 - behavioral harness

- Reusable fixture repositories for debugging, security, API, frontend, database, deployment, and agent-reliability tasks.
- Agent-run adapters for environments that expose a deterministic CLI/session harness.
- Baseline-versus-skill experiments with fixed prompts and seeded defects.
- Precision/recall reporting for scanner-backed skills.
- Windows/macOS/Linux artifact and cross-platform fixture expansion.

## v0.3 - ecosystem adapters

- Product-specific install adapters only where they add value beyond .agents/skills.
- Optional Playwright CLI/MCP browser adapter with isolated profiles.
- Optional package/advisory grounding adapters.
- Machine-readable compatibility capabilities by agent/product/version.

## Backlog deliberately not promoted to standalone skills

- generic write-clean-code advice;
- generic refactoring;
- generic code review;
- generic shell/browser usage;
- generic documentation writing;
- generic repository onboarding.

These remain normal agent capabilities or parts of more specific evidence-producing skills unless future research identifies a distinct trigger and validation contract.
