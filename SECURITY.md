# Security policy

## Reporting a vulnerability

Please use GitHub private vulnerability reporting for this repository when available. Include the affected path/version, impact, a minimal reproduction using synthetic data, and a proposed mitigation if known.

Do not place real credentials, private-system data, or destructive proof-of-concept payloads in a public issue.

## Scope

Security reports may cover the installer/update/remove logic, deterministic helpers, skill instructions that could cause unsafe actions, CI configuration, or published repository content.

The project does not claim that following a skill guarantees secure software. Security skills organize checks and evidence; scanners and agent judgments can have false negatives and require system-specific review.
